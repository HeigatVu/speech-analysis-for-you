## New in v3

### T21: Corpus intake — format probe + continuous-recording split + manifest  [queued]

**Description:** The corpus is 5 participants × 1 continuous recording each × 11
elicitation tasks, 44.1 kHz / 12-bit, no boundary metadata anywhere in `speech_features`
(the batch manifest is one row per recording:
`{recording_id, audio_path, transcript_path, target_speakers, task_spec_path}`,
`src/speech_features/extraction.py:62`). This task: (1) probes the *real* on-disk format
of a sample file — `wave.getsampwidth()`, frame rate, peak sample value, and whether
12-bit samples are packed (1.5 bytes/sample, `wave` will misread this) or right-justified
in a 2-byte container (loads fine but ~24 dB below full scale, per `_SCALE_BY_WIDTH` in
`src/speech_features/audio.py:22`); (2) splits each continuous WAV into 11 per-task clips
using session timing notes; (3) writes a batch manifest CSV with one row per clip, plus a
per-task-spec JSON where the task has one (picture description, recall, phonemic/semantic
fluency — see `src/speech_features/schema.py:454`).

**Acceptance criteria:**
- [ ] the format probe reports sample width (bytes), packing (packed vs. container-aligned),
      frame rate, and peak amplitude for at least one file per participant, committed as a
      short findings note
- [ ] 5 × 11 = 55 per-task clips exist as valid standard-PCM WAV (readable by
      `speech_features.audio.read_wav` without raising)
- [ ] a batch manifest row exists for every clip with `recording_id` and `audio_path`
- [ ] the manifest and every clip filename contain only `recording_id` and relative paths —
      no participant name in any filename or manifest field (grep the manifest for the
      5 participants' names finds nothing)
- [ ] if 12-bit samples are found packed (not container-aligned), the finding is recorded
      and a pre-convert step (e.g. `sox`/`ffmpeg` to 16-bit) is added before the split, not
      silently absorbed

**Verification:**
- [ ] `python -m speech_features.audio` smoke-read on all 55 split clips, zero raises
- [ ] `grep -i "<participant name>" manifest.csv` for each of the 5 names → no match

**Dependencies:** None
**Files likely touched:** a new `scripts/corpus_intake.py` (or `tests/say_transcribe/data/`
tooling), the manifest file, split clips (outside git, per the existing `data/*` gitignore rule)
**Estimated scope:** M
**Delivery branch:** `feature/vietnamese-transcription-pipeline-task-21-corpus-intake`
