# Port batchalign2 and sherpa-vietnamese-asr techniques into say_transcribe

## Objective

Close the gaps found by comparing `say_transcribe` with its declared baselines (`TalkBank/batchalign`, `FranklinChen/talkbank-tools`; the Python reference is batchalign2) and borrow three techniques from `welcomyou/sherpa-vietnamese-asr`. Two correctness bugs in the phase-2 `tag` path are fixed, retrace and filler markup is added to the drafts, CHAT output is checked by `chatter validate`, and three ASR/VAD robustness fixes address the failed pilot gates (VAD coverage 87.6% vs 95%, zero or negative spans, one surviving repetition loop).

## Decisions

- **Two-phase tier workflow stays.** `run` writes the main tier plus `%wor`; `tag` adds `%mor`/`%gra` afterwards. Automatic output goes to new files and never overwrites manual transcripts.
- **Markup is never deleted.** Retraces and fillers are marked in the main tier (`[/]`, `&-ờ`); every content word stays in `%wor`.
- **`%mor` follows batchalign2.** Retraced words, fillers, `xxx`, annotations and pauses are left out of Stanza input and `%mor`/`%gra`; feats become CHAT suffixes with a single `|`.
- **Sherpa techniques taken:** quiet-audio VAD boost with a retry pass, silence-snapped ASR window cuts, consecutive-repeat guard. Not taken: mono downmix (AGENTS.md forbids it), filler deletion, NaturalTurn backchannel absorption, ROVER, Zipformer, GECToR punctuation.
- **ASR audio is never changed** by the VAD boost: the boosted copy is used only for detection.
- **Window cuts never exceed 20 s**, which keeps the GPU attention-cache ceiling documented in `asr.py`.
- **Repeat guard is consecutive, not n-gram deletion.** Short valid repeats ("một một bảy", "ừ ừ") survive, because sherpa found n-gram removal breaks Vietnamese.

## Repository and implementation context

- Python >=3.10; transcription code under `src/say_transcribe/` (`asr.py`, `vad.py`, `morphosyntax.py`, `cli.py`, `chat_writer.py`, `word_grouping.py`); CHAT codec in `src/speech_features/formats/chat.py`.
- Follow `AGENTS.md`: NFC Vietnamese text untouched, lazy ML imports, offline unit tests on synthetic fixtures, no absolute paths, transcript text or raw exceptions in logs or reports.

## Data classification

- **Transcript text and audio** are personal data. They stay out of the diff, tests (synthetic strings only), logs and reports.
- **Tokens (Hugging Face)** are never read or written by this work.
- **Pilot recordings** are used only for the local verification run; outputs go to new files outside the repo.

## Acceptance criteria

1. A reviewed `.cha` containing `<tôi đi> [/] tôi đi &-ờ xxx [: x] (.) .` yields `%mor` and `%gra` whose item counts equal the countable words plus the terminator, and the parse round-trips unchanged.
2. `MorItem.format_mor` never emits more than one `|` for UD feats such as `Number=Plur|Person=1`.
3. `run` drafts mark an immediately repeated n-gram (n=1..4) with `[/]` and standalone Vietnamese fillers with `&-`; no word is removed and `%wor` still lists every content word.
4. A test builds a synthetic session and runs `chatter validate` on it, and the test actually runs (chatter installed), not skipped.
5. A run of one token repeated 8 or more times consecutively is suspected as a repetition loop ("hai" x55 flagged); "một một bảy" and "ừ ừ" are not.
6. ASR window cuts land at the lowest-energy 300 ms run within 2 s before the hard cut; all windows are at most 20 s and cover the input without gaps or overlap; offsets stay on the master timeline.
7. `get_speech_windows` runs the detector on a peak-boosted copy (peak -23 dBFS, only when quieter), retries once with a lower threshold and shorter minimum speech when nothing is found, and leaves the input array unchanged.
8. `python -m pytest tests -q` and `python -m ruff check src tests` pass offline with no rule suppressed; no heavy ML import happens at module import time.
9. The diff contains no audio, transcripts or model outputs and touches nothing on the danger list.

## Done line

A green pull request in which all nine criteria hold, the tests and lint pass offline, and a local re-run of `say-transcribe run` and `tag` on a pilot session produces output that `chatter validate` accepts.

## Amendment 2026-10-03: verified tier rules

Verified against `TalkBank/chatter` docs and `chatter validate` 0.28.0 (criteria 1 to 4 hold as written, with these refinements):

- `%mor`/`%gra` align to words, `,` and the terminator only. Retraced words, `&-` fillers, `xxx`, `(.)`, `&+`/`&~` and annotations are excluded. An utterance with no analysable word has no `%mor`/`%gra`.
- `%wor` aligns to words, fillers and retraced words and keeps the terminator; `xxx` is not written. chatter does not enforce `%wor` membership.
- A timing bullet follows the terminator after a space, never a tab; `@Media` ends in `, unlinked` when no utterance or word is timed.
- `%mor` features are `-Val` suffixes; none for ADP, ADV, CCONJ, INTJ, NUM, PART, SCONJ, SYM, X, PUNCT.
- Underthesea compounds (`_`) are accepted by chatter and kept.
