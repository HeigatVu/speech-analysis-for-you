# Plan: batchalign2 and sherpa-vietnamese-asr techniques

Spec: `SPEC-2026-10-03.md`.

## Shape of the change

Seven small tasks on one run branch `port-batchalign2-retrace-filler`, one commit per task, one pull request. Changes stay under `src/say_transcribe/`, `src/speech_features/formats/chat.py`, `tests/`, `src/say_transcribe/README.md` and this docs directory. Each task starts from a failing test.

### Tag path (batchalign2)

- **T1** `src/speech_features/formats/chat.py` (`_item_kind`, item split at the two `.split()` sites) learns `<a b> [/]`, `a [/] a`, `[: x]`, `[= x]`, `[*]`, `(.)`, `xxx`, `yyy`. `src/say_transcribe/cli.py::_reviewed_records` sends only countable words to `project_morphosyntax`.
- **T2** `src/say_transcribe/morphosyntax.py::MorItem.format_mor` converts UD feats to `-Val` suffixes (one `|`). Check batchalign2 `morphosyntax/ud.py` for the mapping before porting.

### Draft markup and validation

- **T3** New pure function (in `word_grouping.py`, or `cleanup.py` if it does not fit) marks repeated n-grams (n=1..4, longest first) as `[/]` and fillers {ờ, ừ, à, ơ, ừm, ờm} as `&-`, compared after NFC and lowercasing. `chat_writer.py` renders the markup and keeps every content word in `%wor`. Ceiling: `một một bảy` is marked too; add a `ponytail:` note.
- **T4** `tests/say_transcribe/test_chatter_validate.py` builds a synthetic session with `format_chat_session` and runs `chatter validate`, skipped only when `shutil.which("chatter")` is None (same pattern as `NEEDS_FFMPEG` in `test_profile.py`). Install chatter locally so it runs; record the version in `src/say_transcribe/README.md`. Fix any error it finds in `chat_writer.py`.

### ASR and VAD robustness (sherpa)

- **T5** `asr.py::_is_suspected_repetition` first reproduces why "hai" x55 slips through, then adds a consecutive-run check (>= 8 identical normalized tokens).
- **T6** One shared pure helper `_window_bounds(audio, max_len=20 s, search=2 s)` replaces the fixed `range(0, n, 20 s)` loops in `PhoWhisperBackend.transcribe_audio` and `Qwen3AsrBackend.transcribe_audio`. Cut at the midpoint of the lowest-RMS 300 ms run in the last 2 s; fall back to the hard cut.
- **T7** `vad.py::get_speech_windows` runs detection on a boosted copy (peak -23 dBFS, 0.071, only when quieter) and retries once (threshold 0.3, min speech 150 ms) when nothing is found. `_load_silero_detector`'s `detect` accepts the minimum-speech value.

## Ordering

T1, T2, T5, T6, T7 depend on nothing. T3 depends on T1 (parser) and T5 (loops already `xxx`). T4 depends on T2 and T3.

## Verification (per task and per run)

- `HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python -m pytest tests -q`
- `ruff check src tests`
- e2e: `pytest tests/say_transcribe/test_cli.py tests/say_transcribe/test_chat_writer.py -q`
- All new tests offline with synthetic fixtures; no model downloads, no GPU.
- Local real-data check after the last task: re-run `say-transcribe run` and `tag` on a pilot session to new files, compare against the 2026-09-24 pilot report (repetition loops, zero or negative spans, VAD coverage), and run `chatter validate` on both outputs.

## Risks and handling

- **chatter install fails:** report it, never count a skipped test as passing; the run records a blocker rather than weakening the check.
- **Retrace heuristic marks valid repeats:** the reviewer corrects it in phase 1; the ceiling is documented in code.
- **Quieter-frame search finds no gain:** the hard 20 s cut is the fallback, so behaviour never gets worse than today.
- **GPU unavailable for the pilot re-run:** record it as not run; unit evidence stands on its own.
