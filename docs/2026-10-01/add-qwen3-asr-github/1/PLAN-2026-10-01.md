# Plan: Qwen3-ASR vs PhoWhisper-large; pyannote vs WavLM

Spec: `SPEC-2026-10-01.md`. Research: `RESEARCH-2026-10-01.md`.

## Shape of the change

Three code tasks, then the experiment node runs the real benchmark. One run branch `add-qwen3-asr-github`, one commit per task, one pull request for the run; nothing outside `src/say_transcribe/`, `tests/say_transcribe/`, and this docs directory changes.

### Backend and CLI surface

- `src/say_transcribe/asr.py`: add `Qwen3AsrBackend` beside `PhoWhisperBackend`. Constructor: `model_id="Qwen/Qwen3-ASR-1.7B-hf"`, `device="cpu"`, optional `revision`, optional `language="Vietnamese"`. `load()` lazily imports `transformers` (`AutoProcessor`, `AutoModelForMultimodalLM`) and raises `AsrError("MODEL_UNAVAILABLE", ...)` on failure. `transcribe_audio(audio_16k_mono)` runs `processor.apply_transcription_request(audio=<array>, sampling_rate=16000, language=...)`, `model.generate(...)`, `processor.decode(..., return_format="transcription_only")`, and emits one `AsrSegment` with null word timings (the Qwen3 forced aligner does not support Vietnamese).
- `src/say_transcribe/cli.py`: add `--asr-model {phowhisper-medium,phowhisper-large,qwen3-asr}` to `run`, `compare`, `study` (default keeps `vinai/phowhisper-medium`); add `--diarizer {pyannote,wavlm}` (default `pyannote`) replacing the silent WavLM fallback; add subcommand `benchmark` with `--task asr|diarization`, `--manifest`, `--out`.
- `src/say_transcribe/diarize.py`: `PyannoteBackend.load()` distinguishes a missing/unauthorized token (`AsrError("PYANNOTE_TOKEN_MISSING", ...)`) from other load failures (`AsrError("MODEL_UNAVAILABLE", ...)`); no behavior change to `WavlmClusterBackend` or `assign_speakers`.
- `say_transcribe/benchmark.py` (new): report writer shared by both tasks — per-session rows plus aggregate rows, JSON + Markdown, pseudonymous ids and relative paths only.

### Scoring (shared with the experiment node)

- ASR: WER (word-level) and CER from `evaluate.py` normalization, identical for both models.
- Diarization: utterance-level PAR/INV role agreement after overlap-based alignment of diarized turns to reference turns; per-session speaker/turn counts recorded for both backends.

### Experiment and thresholds

`experiment_run` executes:

```
.venv/bin/python -m say_transcribe.cli benchmark --task asr        --manifest <pilot manifest> --out <run>/experiment
.venv/bin/python -m say_transcribe.cli benchmark --task diarization --manifest <pilot manifest> --out <run>/experiment
```

`experiment/METRICS.json` carries these thresholds (declared here before the run; the run records the metrics):

| metric | op | value | meaning |
| --- | --- | --- | --- |
| `asr_cells_scored` | == | 2 | both models × every surviving referenced session produced finite WER and CER |
| `diarization_cells_scored` | == | 2 | both diarization backends × every surviving referenced session produced role-agreement numbers |

Comparative results (which model wins each metric, per-session tables, runtimes) are report content, not thresholds: the deliverable is the measured comparison, and the thresholds prove it was measured completely. A cell blocked by model gating fails its threshold honestly instead of being substituted.

**Amendment 2026-10-02 (before the recorded run):** the pilot corpus lost its second reference to external file operations — `find /shared-data/hcmiu-bhl-corpus -name '*.cha'` returns only `file-information.cha` and `audio/p001/p001.cha` (the `transcript/` directory and `audio/p002/p002.cha` vanished with directory mtimes 2026-10-02 01:42–01:46). Cell counts are `models × referenced sessions`, so the declared values drop 4 → 2 per task; `p002` stays in the manifest and its rows carry `REFERENCE_UNREADABLE`. The completeness rule ("every session with a verified reference is scored") is unchanged.

## Risks and handling

- HF gating for pyannote: needs accepted conditions on `pyannote/segmentation-3.0` and `pyannote/speaker-diarization-3.1` plus a token in the environment. If blocked at experiment time, METRICS thresholds fail, the graph loops, and the run reports the gap with a stable error code; nothing substitutes WavLM silently.
- Qwen3-ASR-1.7B CPU runtime: per-session runtime is recorded in the report; no threshold depends on it.
- Two references only: report is labelled exploratory (SPEC states this).
