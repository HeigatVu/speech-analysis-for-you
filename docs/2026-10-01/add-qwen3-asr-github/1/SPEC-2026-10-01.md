# Add Qwen3-ASR and benchmark it against PhoWhisper-large; compare pyannote and WavLM diarization

## Objective

Integrate Qwen3-ASR (QwenLM/Qwen3-ASR on GitHub, roughly 1.7B parameters) as a selectable ASR backend in `say_transcribe` and measure its transcription performance against PhoWhisper-large on the pilot corpus. Reactivate pyannote as the primary speaker-diarization backend — the human confirmed and agreed to everything pyannote requires, including its Hugging Face gating and terms, in place of relying on WavLM — and measure pyannote against the existing WavLM clustering backend on the same recordings.

The outcome is two reproducible benchmark reports and measured model choices: (1) Qwen3-ASR versus PhoWhisper-large transcription error, and (2) pyannote versus WavLM speaker attribution quality.

## Decisions

- **Backend contract.** `Qwen3AsrBackend` speaks the same interface as `PhoWhisperBackend` in `src/say_transcribe/asr.py`: lazy `load()`, `transcribe_audio()` over the in-memory 16 kHz mono view, and the existing `AsrResult` / `AsrSegment` / `WordTiming` normalization shared so both models score through one path. All PyTorch/transformers imports stay inside `load()`.
- **Comparison baseline.** The ASR benchmark compares exactly two models: Qwen3-ASR and PhoWhisper-large (`vinai/phowhisper-large`, pinned in the benchmark). The CLI default stays `vinai/phowhisper-medium` unless measured results justify changing it in a later decision.
- **Checkpoint pinning.** The Qwen3-ASR checkpoint is the official variant published in `github.com/QwenLM/Qwen3-ASR`; `RESEARCH-2026-10-01.md` records the exact Hugging Face model id, the transformers version requirement, and the inference entry point, and `PLAN-2026-10-01.md` pins them as constructor defaults.
- **pyannote primary.** `PyannoteBackend` (`pyannote/speaker-diarization-3.1`) is the default diarization path and honors the Hugging Face token from `auth_token` or the environment. The silent WavLM fallback currently in `src/say_transcribe/cli.py` becomes explicit selection (a `--diarizer` choice of `pyannote` or `wavlm`): a pyannote failure raises a stable error code instead of silently switching models. No code path auto-accepts model terms; the human's consent is recorded in the run evidence, not simulated in software.
- **Benchmark surface.** Extend the `say-transcribe` CLI with a `benchmark` subcommand, `--task asr|diarization`, taking an approved manifest and an output directory. It writes one JSON report plus a short Markdown summary into the run's experiment directory (`.agent-state/runs/<date>/<slug>/<version>/experiment/`). Reports carry pseudonymous session ids and metrics only: no transcript text, no absolute paths, no raw exceptions (AGENTS.md redaction rules).
- **ASR scoring.** Word-level WER and character-level CER against verified human `.cha` references, through the normalization already used by `src/say_transcribe/evaluate.py`, identical for both models: Vietnamese surface syllables preserved (tone marks, `đ`, NFC, punctuation), no cross-utterance word grouping. Decoding settings are the documented defaults of each model, fixed before the run and recorded in the report; no per-model tuning.
- **Diarization scoring.** Utterance-level speaker-role agreement (`PAR` / `INV`) against reference speaker tiers, after overlap-based alignment of diarized turns to reference turns, plus per-session speaker counts and turn counts recorded for both backends so disagreements are inspectable.

## Repository and implementation context

- Python project, Python >=3.10; command entry points are `say-transcribe` and `say-features`. Transcription code is under `src/say_transcribe/` (`asr.py` backends, `diarize.py` backends, `cli.py` commands, `evaluate.py` scoring, `study.py` study layer).
- Follow `AGENTS.md`, the local Batchalign repository maps under `docs/2026-09-21/repo-map/1/`, and the audio/channel, provenance, privacy, lazy-dependency, and opt-in-profile rules there.
- Explicit channel selection via `channel_index`; never mean-downmix multichannel audio to mono. Native PCM stays on disk untouched; the 16 kHz float32 mono ASR view exists only in memory. SHA-256 of the master audio is verified before any decode.
- Keep PyTorch, transformers, pyannote, and WavLM imports lazy. Unit tests run offline with synthetic fixtures and never download model weights or require a GPU.

## Benchmark design

- **Sessions.** The pilot inventory holds five recordings (`p001`–`p005`) and two verified `.cha` references. Score every session that has a verified reference, for both ASR models and both diarization backends, from the same selected-channel view and the same master-hash pre-check. With two references the report is exploratory: it can rank these models on these recordings but cannot make population claims.
- **Parity.** All four model runs see identical input audio, identical reference normalization, and identical session sets. A cell that cannot be measured is recorded with its stable error code (for example a gated model that cannot load without a token); models are never substituted for one another silently.
- **Fairness.** Decoding settings are each model's documented defaults, fixed in the plan and echoed in the report. No arm gets tuning the other does not.

## Acceptance criteria

1. `Qwen3AsrBackend` is integrated in `src/say_transcribe/asr.py`, selectable from the CLI, lazy-loaded, with stable `AsrError` codes; offline unit tests cover its output parsing, normalization, and error paths with synthetic fixtures.
2. `say-transcribe benchmark --task asr` writes WER and CER for Qwen3-ASR and PhoWhisper-large per referenced session plus aggregate rows into the experiment report.
3. `say-transcribe benchmark --task diarization` writes speaker-role agreement and turn/speaker counts for pyannote and WavLM on the same sessions; the CLI no longer silently falls back to WavLM; explicit `--diarizer pyannote|wavlm` works for both.
4. pyannote is the default diarization backend and its Hugging Face token path is honored; a missing token or missing access fails with a stable error code naming the condition, not a stack trace.
5. `python -m pytest tests/say_transcribe/ -q` and `python -m ruff check src/say_transcribe tests/say_transcribe` pass; no heavy ML import happens at module import time.
6. The diff contains no audio, no transcripts, no model outputs, and touches nothing on the danger list (no schema/data migrations, no data destruction, no production writes, no credential changes, no history rewrites).
