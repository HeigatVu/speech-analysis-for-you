**Goal:** Run Stanza `vi` (UD-VTB) pretokenized on T7's `_`-joined words, MWT explicitly disabled,
and project the parse into `%mor`/`%gra` items per the render.py rules (SPEC §3, PLAN §Code-reading
map).

**Acceptance:**
- A Chatter fixture with `_`-joined words in `%mor`/`%gra` validates before any real-Stanza test is
  trusted (open question 1 in SPEC §8).

  `target.replace("_", "")`).

  terminator.
- `,` renders as `cm|cm`.

  utterance only, main tier line and bullet are kept.
- Offline unit tests run against a fake Stanza pipeline; no real UD-VTB model download in CI.
