## T13: §8 pilot comparison — VAD windowing, CTC alignment, `compare` CLI [done]

**Goal:** Implement the SPEC §8 pilot-comparison amendment on top of T12's timing repair: Silero
VAD-guided ASR windowing, Vietnamese CTC forced alignment, the `compare` subcommand producing all
three variants, and the text-quality/timing acceptance gates in §8. Distinct from T12's
timing/diarization-repair scope.

**Acceptance:**
- `get_speech_windows` (Silero VAD, ONNX) and `merge_asr_windows` (WhisperX-style greedy fold,
  <=20s) produce the ASR windows for the two VAD-guided variants; `VAD_UNAVAILABLE` and
  `INVALID_VAD_WINDOWS` are distinct, tested error paths.
- `align_words` (Vietnamese CTC, `nguyenvulebinh/wav2vec2-base-vi-vlsp2020`) times the aligned
  variant; a word the aligner cannot encode (digits, foreign script, `<unk>`) stays untimed without
  nulling out the rest of the utterance; `ALIGNMENT_UNAVAILABLE` is a distinct, tested error path.
- A Whisper decode that looks like a repetition loop or `<unk>` is replaced with the CHAT `xxx`
  marker and flagged with the `ASR_REPETITION_SUSPECTED` warning, never emitted as real text (§8
  text-quality gate).
- `say-transcribe compare` writes baseline/VAD/VAD+aligned variants for one session, validates
  `--vad-threshold` and `--expected-sha256` before any I/O, and never overwrites an existing file
  (`OUTPUT_EXISTS`).
- `extract_session_items` scores an untimed draft or a transcript with malformed headers via a
  lenient main-tier scan instead of raising `InvalidChatError`; the strict CHAT parser used
  elsewhere is unchanged.
- p001 acceptance measured per §8: zero repetition loops/`<unk>` reach the main tier untagged,
  aligned-variant timed utterances >= 90%, bag-of-syllable recall >= baseline's own recall, VAD
  windows touch >= 95% of human-timed utterances.
