# Specification: `say_transcribe` version 4

**Status:** implementation-ready revision  
**Research:** [RESEARCH-2026-09-21.md](./RESEARCH-2026-09-21.md)  
**Plan:** [PLAN-2026-09-21.md](./PLAN-2026-09-21.md)

## 1. Objective and non-goals

Convert approved spans from the private Vietnamese pilot recordings into reviewable participant-safe SAY JSON v2, optional validated CHAT, and a label-free `speech_features` manifest. The production baseline is one lazy `vinai/PhoWhisper-medium` backend with a fake backend for tests.

The native explicit-channel task clip is authoritative. A separate opt-in `tell-inspired-v1` profile exists only for A/B analysis of ASR and timing. It is not a replacement for native acoustic measurements and does not make a clinical claim.

Out of scope: automatic task-boundary inference, automatic role assignment, multiple ASR engines, LLM correction/segmentation, forced alignment, morphosyntax, diagnosis labels, confidence queues, and publishing denoised/band-limited pitch, HNR, energy, or spectral features.

## 2. Pilot facts and assumptions

- Five continuous WAV masters (~92.3 minutes): one 44.1 kHz and four 48 kHz, stereo, signed 32-bit containers.
- Three sessions have active left audio and an almost-silent right channel; mean downmix would attenuate the useful signal. Channel selection is therefore explicit and mandatory.
- Eleven protocol tasks are not all boundary-annotated; runtime never guesses missing spans.
- Existing CHAT is incomplete/invalid in places and is a curation aid, not a gold set.
- NVIDIA hardware is visible but the driver currently fails `nvidia-smi`; the real model pilot is blocked.
- Source masters, transcripts, annotations, clips, predictions, and sidecars remain outside git. Synthetic fixtures only are tracked.

## 3. Input and output contracts

### 3.1 Approved annotations

`session-annotations.v1.json` contains relative `source_audio`, a lowercase SHA-256, explicit `channel_index`, `review_status`, and ordered task/turn millisecond bounds. Only `review_status: "approved"` reaches `run`; `diarize` may write a draft copy. Roles are only `participant` or `investigator`; ambiguous overlap is omitted, never guessed.

Reject unknown keys, absolute paths, malformed hashes, duplicate IDs, non-finite/non-integer bounds, out-of-range spans, overlaps, stale hashes, and invalid channels with `INVALID_ANNOTATIONS` or a more specific stable code.

### 3.2 Native track

T2 verifies the master hash, selects the declared channel, and crops integer sample boundaries without resampling, loudness changes, codec round-trips, denoising, or band limiting. The same clip may expose an in-memory 16 kHz mono float view for PhoWhisper. The native clip and native feature results remain the baseline.

### 3.3 Processed artifact

`preprocess` accepts only a validated native clip and `--profile tell-inspired-v1`. It writes:

- one mono, signed PCM16, 16 kHz WAV;
- one `tell_preprocess_v1.json` sidecar with schema/profile IDs, source/output hashes, public media facts, tool/model versions and revisions, stage configuration and measured loudness, integer-sample VAD intervals, and issue codes.

The sidecar contains no transcript, token, label, demographic, credential, waveform, or absolute path. Derived files are ignored by git.

The artifact must have deterministic sample length: allow only trailing GSM padding up to 319 samples; fail on larger drift, unexpected clipping, non-finite samples, or hash mismatch. Every subprocess uses an argument list, bounded timeout, private temporary directory (0700), and atomic output replacement.

## 4. `tell-inspired-v1` processing stages

This is inspired by TELL’s four-stage description, but it is not claimed to reproduce unpublished TELL settings.

1. **Common-channel normalization (SoX + GSM Full Rate).** Input is already the explicitly selected mono channel. Use SoX 14.4.2 with GSM support for an 8 kHz GSM Full Rate round-trip (13 kbps), decode to signed PCM16, resample with high-quality `rate -v` to 16 kHz, then apply a high-pass at 200 Hz and low-pass at 3.4 kHz. Do not add a separate SoX `compand`: the paper’s “compression factor of 8” describes the GSM codec ratio. Missing SoX or GSM support fails with `SOX_UNAVAILABLE`/`SOX_GSM_UNAVAILABLE`.
2. **Loudness normalization (FFmpeg).** Use two-pass `loudnorm` with EBU target `I=-23 LUFS`, `LRA=7 LU`, `TP=-2 dBTP`, `linear=true`, `dual_mono=false`. Persist only measured public values. Unmeasurable or clipping output fails with `LOUDNESS_UNMEASURABLE`.
3. **Denoising (DeepFilterNet3).** Use the pinned optional artifact `DeepFilterNet3` v0.5.6, model ZIP SHA-256 `49c52edc8947ae1f9bf50d81530beaf3a2c3245aeaf34b6f31ff535cd22284d2`, with delay compensation. Keep the dependency lazy/isolated; never auto-download in a unit test. Missing or altered model fails with `DENOISER_UNAVAILABLE`/`MODEL_INTEGRITY_ERROR`.
4. **VAD (Silero ONNX).** Use Silero VAD v6.2.2 CPU ONNX, model SHA-256 `1a153a22f4509e292a94e67d6f9b85e8deb25b4988682b7e174c65279d8788e3`, 16 kHz input, threshold 0.5, minimum speech 250 ms, minimum silence 100 ms, padding 30 ms. Intervals are half-open integer sample ranges. Missing/invalid model fails with `VAD_UNAVAILABLE`/`MODEL_INTEGRITY_ERROR`.

Silero is multilingual but Vietnamese performance is not assumed; T11 must manually score a small private interval set before promotion.

## 5. Feature behavior

Existing native timing/acoustic packs remain unchanged. The new `silero_timing` pack is opt-in and consumes only a validated sidecar plus approved participant turns. It intersects Silero speech intervals with participant intervals, excludes examiner/ambiguous time, and reports:

`svad_speech_s`, `svad_speech_ratio`, `svad_speech_segment_count`, `svad_speech_segment_mean_s`, `svad_speech_segment_sd_s`, `svad_pause_count`, `svad_pause_total_s`, `svad_pause_mean_s`, `svad_pause_sd_s`, `svad_pause_median_s`, `svad_pause_max_s`, `svad_pause_rate_per_min`, `svad_pause_proportion`, and `svad_long_pause_count`.

Pause threshold is 0.20 s; long pause threshold is 2.0 s. Valid speech with no pauses returns count/total zero and summary statistics as `NaN` with an issue. Missing target intervals or no speech returns `NaN` plus an issue, never a fabricated zero. Processed pitch/HNR/energy/spectral values are shadow-only in v1 because 200 Hz/3.4 kHz filtering can alter Vietnamese tones and fricatives.

## 6. ASR, speakers, and serialization

- `run` defaults to `--asr-audio native`; processed audio requires explicit `--asr-audio tell-inspired-v1` and a matching sidecar.
- PhoWhisper segments are retained as draft utterances. Tokens are assigned by approved turn midpoint; role changes split utterances; unapproved time is excluded.
- Underthesea 9.5.0 groups Vietnamese syllable tokens by `word_id` without changing surface text, NFC, tone marks, punctuation, or `d`/`đ`.
- JSON v2 is authoritative. `--chat` is a validated derivative and fails closed if Chatter is unavailable or rejects the output.
- Manifest v2 remains backward-compatible. `preprocess_path` is optional and must be relative, hash-checked, and label-free.

## 7. Commands and stable errors

```text
say-transcribe diagnose
say-transcribe diarize ANNOTATIONS.json --out ANNOTATIONS.draft.json
say-transcribe preprocess ANNOTATIONS.approved.json --out OUTPUT_DIR --profile tell-inspired-v1
say-transcribe run ANNOTATIONS.approved.json --out OUTPUT_DIR [--asr-audio native|tell-inspired-v1] [--chat] [--device cuda|cpu]
say-transcribe evaluate GOLD-MANIFEST.json PREDICTIONS_DIR --out REPORT.json
```

Exit codes: `0` success, `2` validation/configuration, `3` unavailable dependency/model, `4` pipeline failure. Stable codes include `INVALID_ANNOTATIONS`, `SOURCE_HASH_MISMATCH`, `UNAPPROVED_ANNOTATIONS`, `INVALID_AUDIO_CHANNEL`, `SOX_UNAVAILABLE`, `SOX_GSM_UNAVAILABLE`, `FFMPEG_UNAVAILABLE`, `LOUDNESS_UNMEASURABLE`, `DENOISER_UNAVAILABLE`, `VAD_UNAVAILABLE`, `MODEL_INTEGRITY_ERROR`, `PREPROCESS_ALIGNMENT_ERROR`, `INVALID_PREPROCESS_ARTIFACT`, `GPU_UNAVAILABLE`, `MODEL_UNAVAILABLE`, `WORD_GROUPING_UNALIGNED`, and `CHAT_VALIDATION_FAILED`.

Logs and errors expose only stable codes, positions, pseudonymous IDs, public versions, and hashes. Never emit transcript text, tokens, waveform data, absolute paths, credentials, demographics, diagnosis, or raw exceptions.

## 8. Evaluation and promotion gate

Development uses the most complete curated session; held-out uses non-overlapping participant windows from other sessions. Report syllable error rate (primary), CER, frozen-Underthesea WER (diagnostic), 250 ms-collar DER (diagnostic), timing agreement against manually scored Silero intervals, format pass rates, counts, and seeded 2,000-resample clip-bootstrap intervals. No clinical threshold is invented before measurement.

Promote `tell-inspired-v1` only when it has no native-track regression on the predeclared ASR/format gate, its VAD interval agreement is documented, artifact invariants pass, and reviewers accept the Vietnamese error analysis. Otherwise keep it analysis-only.
