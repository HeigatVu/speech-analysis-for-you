### T3: CHAT subset exporter  [queued]

**Description:** `export/chat.py` — `to_chat_text(recording)` producing the SAY CHAT subset
(`@Begin`, `@Languages:\tvie`, `@Participants` with derived 3-letter `[A-Z]{3}` codes,
`@ID`, `@Media`, `*CODE:` tiers, `%xaud` utterance + word bullets, optional `%mor`/`%gra`,
`@End`). Disfluency tokens carry their CHAT marker **in `text`** (`&uh`, `ple-`, `[/]`,
`[//]`) so `_item_kind` re-derives the kind on reload. Word bullets are emitted only when a
segment has ≥2 timed content tokens.

**Acceptance criteria:**
- [ ] `speech_features.load_document(<written .cha>)` returns a `SpeechDocument` whose
      `warnings` contain **no** `UNSUPPORTED_CHAT_TIER` for known data
- [ ] speaker codes are valid `[A-Z]{3}` and stable for the same input
- [ ] a filler / fragment token round-trips to `kind` `filler` / `fragment` after reload
- [ ] `%mor`/`%gra` lines appear only when every content token has a value; item count
      equals content-token count
- [ ] `to_chat_text` raises a `TranscribeError` when `recording.media_path` is empty (CHAT
      needs `@Media`)

**Description:** `stages/disfluency.py` + `prompts/disfluency.vi.txt` — an LLM pass that
