# Neurodegenerative speech-feature evidence sources

Authoritative sources behind the evidence tags (`systematic_review`,
`multi_study`, `single_study`) attached to catalog features and evidence
inventory rows. The `standard_feature_set` and `derived_companion` evidence
levels reference the openSMILE standard set below and SAY's own determinism
respectively.

No reviewed source in this research pass establishes Vietnamese clinical
cutoffs for these disorders; cross-language features are hypotheses for
Vietnamese validation.
